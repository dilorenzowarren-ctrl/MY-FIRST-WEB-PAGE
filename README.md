## Accessibility and Design Improvements

### Accessibility Testing
I tested all three pages of my website using the WAVE Web Accessibility Evaluation Tool. The pages showed zero accessibility errors and zero contrast errors at the time of testing.

### Accessibility Improvements
- Added a skip navigation link so keyboard users can move directly to the main content.
- Added visible keyboard focus indicators to help users identify the selected element.
- Used semantic HTML elements, including header, navigation, main, and footer.
- Added descriptive alternative text to images.
- Added labels and instructions to the contact form fields.
- Used required fields and appropriate input types to support form validation.

### Color Contrast
I used contrasting text and background colors to improve readability and meet WCAG AA contrast requirements.

### Gestalt Principles
- **Proximity:** Related information is grouped together in sections and cards, making the website easier to follow.
- **Similarity:** Consistent colors, fonts, headings, and card styles help create a unified appearance across all three pages.

### Consistent Design
I maintained a consistent color palette and typography throughout the Home, Projects, and About pages.
